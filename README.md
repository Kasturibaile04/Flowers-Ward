# 🌸 Flowers Ward

An interactive hand-tracking web application where beautiful flowers bloom and follow your fingertips in real time. Built using React, Vite, and MediaPipe, this project creates a fun and immersive visual experience using your webcam.

---

## ✨ Features

- 🌼 Real-time hand tracking
- 🌺 Flowers follow your fingertip movements
- 📷 Webcam integration
- ⚡ Smooth animations
- 📱 Responsive design
- 🚀 Fast performance with Vite

---

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- MediaPipe Tasks Vision
- HTML5
- CSS3

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/Kasturibaile04/Flowers-Ward.git
```

Go to the project folder:

```bash
cd Flowers-Ward
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
